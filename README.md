# sentinai-python

Python SDK for sending errors and logs to [SentinAI](https://sentinai.onrender.com).

**Status: pre-alpha, design only.** There is no installable package yet. The plan
is in [DESIGN.md](DESIGN.md).

The goal is a small SDK with no dependencies that never slows down or breaks the
application it runs in, and that keeps personal data out of what it sends.
